# Snake — Arcade IFES

Snake é um jogo arcade educativo para o navegador. A cobra come frutas para crescer e pontuar. A cada 5 frutas aparece uma fruta "?", que abre uma pergunta de múltipla escolha. Acertar dá um upgrade temporário; errar mostra a explicação e acelera a cobra, mas nunca encerra a partida.

O jogo foi feito com o fluxo do **Spec-Kit**: especificação, plano, tarefas e implementação. Os artefatos ficam em `specs/001-snake-game/`.

## O que há nesta documentação
